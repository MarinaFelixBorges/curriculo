# Portfólio · Marina Felix Borges

Site de portfólio profissional — marketing digital, live marketing, endomarketing, dados e conteúdo.

🔗 No ar em: https://marinafelixborges.github.io/curriculo/

## Páginas

- `index.html` — página principal (sobre, experiência, habilidades, formação, contato)
- `certificados.html` — galeria de certificados (lightbox de PDF/imagem)
- `design.html` — linha do tempo de peças de design
- `sites.html` — linha do tempo de sites desenvolvidos
- `eventos.html` — galeria de fotos e vídeos de eventos

## Stack

- HTML + CSS + JavaScript puro (sem framework, sem build)
- Fontes: Libre Baskerville + Plus Jakarta Sans (Google Fonts)
- Lightbox de PDF via pdf.js (CDN)

## Deploy

Hospedado no **GitHub Pages** (repositório `curriculo`). Ao enviar os arquivos
para a branch publicada, o GitHub atualiza o site automaticamente em 1–2 minutos.

> Caminhos relativos em todo o site, compatíveis com o subcaminho `/curriculo/`.
